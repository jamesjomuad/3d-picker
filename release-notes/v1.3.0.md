# 3D Picker v1.3.0

This release adds board and collection backup, in-app information pages, and a cleaner Selected Cells card. It also fixes data clearing and web button nesting issues found during pre-build testing.

## ✨ New

### Backup and restore

- Export saved boards and collection entries as a versioned JSON file.
- Share the generated backup from the Android share sheet.
- Import backup files with strict format, version, date, board and collection validation.
- Destructive imports require confirmation and roll back if restore fails.

### In-app information

- **What's New** shows release notes for installed versions.
- **Privacy Policy** explains local storage and the public draw-results request.
- **Licenses** lists runtime dependency licenses.

## 🔧 Improved

- Selected Cells Insights now sits in a simple themed bordered card.
- Active dark-mode tab icons use the app primary color.
- Clear App Data now clears cached draw results in memory as well as on device.

## 🐛 Fixed

- Foldable cards no longer place action buttons inside the card toggle button.
- Option sheets no longer mark the backdrop as a button, removing nested-button hydration warnings on web.

## ✅ Verification

- `npm run lint` — passed.
- `npm test -- --runInBand` — 28 suites, 410 tests passed.
- `npx expo-doctor` — 20/20 checks passed.
- `npx expo install --check` — dependencies up to date.
