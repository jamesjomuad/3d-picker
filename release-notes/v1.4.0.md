# 3D Picker v1.4.0

This release adds configurable board sizes and better board actions. It also fixes editing and selection issues found after v1.3.0.

## ✨ New

### Configurable grid size

- Resize a board from 2–20 rows and 2–12 columns in the visual editor.
- Growing a grid fills new cells with `0`.
- Shrinking a grid asks for confirmation before deleting cells.
- Dimensions stay derived from the grid, so saved boards keep the same simple data shape.

### Board card options

- Tap a board card to open More options.
- Use Set Board to choose the active board without leaving the Boards page.
- A success toast confirms the active board change.
- Use Preview to open a read-only grid preview with dimensions.

## 🔧 Improved

- Angle Board selection requires a double tap. Double tap and drag extends the range.
- Editable cells open with an empty field on double tap.
- Edit board actions use one compact row in both editor modes.
- JSON board output keeps each grid row on one line.

## 🐛 Fixed

- JSON Apply validates the current text without requiring Preview first.
- Visual cell edits save before closing the sheet, switching editors, or opening Replace.
- Toast uses a valid Android accessibility role.
