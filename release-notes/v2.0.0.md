# 3D Picker v2.0.0

This release adds cached Results, better Collection tools and more complete Fun Pick generation. It also fixes sheet and selection issues found after v1.4.0.

## ✨ New

### Cached Results

- Results are cached in local SQLite.
- Draw history shows pending and upcoming states.
- Pull to refresh updates cached draws.
- Older results load with cursor-based paging.

### Results filters

- Choose a cached month with the Month chip.
- Page through seven day chips at a time with Older and Newer.
- Search cached draws with the numeric keyboard.
- Month, day and search filters combine.
- Filtered rows show `—` for missing sessions instead of inferred `PENDING`.

### Collection tools

- The selection basket is persisted in SQLite.
- Swipe actions and bulk select speed up basket management.
- Collection detail uses a modal sheet with outside-tap dismissal.

## 🔧 Improved

- Fun Pick accepts straight board walks as well as 90-degree turns.
- Direction filters remain view-only over the full generated batch.
- Hidden checkboxes no longer leave extra spacing in Collection rows.

## 🐛 Fixed

- Contextual sheets hide bottom tabs while visible.
- Outside taps pass through the Collection sheet.
- Select mode toggling and row highlight behave correctly.

## 📦 Download

- Build artifact is not included with this source tag.
