# 3D Picker v1.2.0

This release adds advanced board editing, brings Fun Pick into a bottom sheet, makes result filters multi-select, and lets saved picks be plotted without changing the active board.

## ✨ New

### Board JSON editor
- Switch between **Visual Editor** and **JSON Editor** in Board Edit. Visual stays the default.
- JSON mode highlights syntax, shows line numbers, and reports errors with line and column when available.
- **Preview Changes** validates and compares without changing the board.
- **Apply Changes** persists validated edits, preserves board identity, and updates the visual editor immediately.
- Cancel and mode switches discard only unapplied JSON.

### New board naming
- **New Board** asks for the name before creating the board.
- A default name is prefilled, and an empty name blocks creation.

### Fun Pick, easier to use
- Fun Pick opens as a bottom sheet so the board stays visible.
- Generation is fixed at 3D; Direction chips filter results.
- Digit, direction and L-pattern filters support multiple choices at once.
- **Distinct** grouping removes duplicate result shapes without mutating generated batches.

### Saved-pick plotting
- Collection picks open a detail sheet with an active-board preview.
- A validated one-shot plot previews matching paths with search-style highlights.
- Saved cells stay as a temporary outline; the board grid and active board do not change.

## 🔧 Improved
- Board edit view keeps the grid at the top and places every action in a fixed bottom footer.
- Replace tool buttons are clearer and still match against the original board snapshot.
- Android combination search uses the numeric keyboard.
- Collection basket list is virtualized, with touch targets brought up to size.
- Collection share text is shorter.
- Board cards no longer draw the temporary highlight border.

## 🐛 Fixed
- Every board More-menu action works: Open, Edit, Rename, Duplicate, Favorite, Delete and Cancel.
- Dialogs and option sheets dismiss on outside tap, hardware back, and Cancel.
- Duplicated boards copy their grid independently and do not inherit favorite or active status.
- Confirm dialogs render above sheets and menus.
